- P08-S015 FACT (where the configured value becomes a Python value): on routes L, S and V the YAML text is parsed by `yaml.safe_load` and then validated by Pydantic models; on route R it is parsed only. Current external context (P08-S005 (a), (c)): PyYAML loads the plain scalars `true`, `false`, `on` and `off` as Python booleans; in Pydantic's lax mode an `int` field accepts a float that is an exact integer, a `bool` field accepts the strings listed in P08-S005 (a), and a `str` field has no accepting row for a `bool` input. INTERPRETATION: a bare `off` written for `scoring.v3_hardgate_mode` would reach the `str` field as the Python value `False` and fail validation, so `load_all` would raise and the boot would stop with exit code 5 (P08-S009); this is what the file's own comment guards against ("quoted — YAML reads bare off as false", `config/scoring_weights.yaml` L39).
