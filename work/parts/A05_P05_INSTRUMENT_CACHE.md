## 2. The module and its record (`InstrumentRow`)

P05-S010. HISTORICAL (L9 to L29): the module's own "Locked Design Decisions" IC1 to IC15: IC1 load from `config/instruments.csv` with the seven columns `symbol, instrument_token, exchange, lot_size, tick_size, is_fno, sector`; IC2 `InstrumentNotFoundError` "on unknown symbol/token lookups. Not KeyError"; IC3 a frozen dataclass "with all 7 columns typed"; IC4 to IC11 and IC15 the accessors (`has`, `get_by_symbol`, `get_by_token`, `all_rows` "in load order", `sector` returning "UNKNOWN" if missing, "never raises -- used in risk_engine lambdas", `lot_size` and `tick_size` raising on a miss, `token_map` "used by CandleStore", `count`); IC12 `load(path)` "raises ConfigMissingError if file absent, ConfigSchemaError if any row is malformed"; IC13 "Layer 0-1 (core/). A different set of decisions with the same labels IC1 to IC15 exists in the module specification (section 12, P05-S131).

P05-S011. INTERPRETATION (A01 AUDIT L1337, the list of the sixteen steps of `run_all_startup_checks`, re-read in `utils/startup_checks.py` L1550 to L1660): no startup step checks whether symbols are tradeable; the only cache step is the size check (section 7).

P05-S012. P05-S014. FACT (L54 to L68): the record has no `tradingsymbol`, `name`, `segment`, `instrument_type`, `expiry`, `strike`, `exchange_token` or `last_price` field, and no field that records the data's source, as-of date or load time. INTERPRETATION: no unit is stated for `tick_size` or `lot_size`; the example 0.05 and `orders/price_math.py` L23 to L27 (HISTORICAL: "Most equities trade in 0.05 increments ... Always prefer the instrument's real tick from InstrumentCache") treat `tick_size` as a price step in the unit of order prices, and the comment at L65 treats `lot_size` as a quantity of shares (1 for equity). The current vendor instrument dump carries `tradingsymbol`, `segment` and `instrument_type` columns (part P02, P02-S081, current external context); the cache's file contract has no place for them, and how the writer maps the dump to `symbol` is part P07's.

P05-S015. INTERPRETATION (Python dataclass semantics): with `frozen=True`, assigning to a field of a row raises `dataclasses.FrozenInstanceError`, so rows cannot be changed through ordinary attribute assignment after construction; the annotations are not checked when a row is built, so the types hold only because `load` converts the text (section 4).

## 3. Construction and indexes (`__init__`); duplicate symbols and tokens

P05-S016. FACT (L86 to L94): `InstrumentCache.__init__(self, rows: List[InstrumentRow])` stores `list(rows)` as `_rows` (L92) and builds two dictionaries, `_by_symbol = {r.symbol: r for r in rows}` (L93) and `_by_token = {r.instrument_token: r for r in rows}` (L94). It validates nothing, logs nothing and raises nothing of its own. HISTORICAL (docstring L87 to L91): "Called by load(); not typically called directly." FACT (AST, P05-S001): `__init__` is the only method of the class that assigns an instance attribute.

P05-S017. INTERPRETATION (dictionary-comprehension semantics, confirmed in P05-S007): when two rows share a key, the later row wins. With two rows of one `symbol`, `has`, `get_by_symbol`, `sector`, `lot_size` and `tick_size` see only the later row; with two rows of one `instrument_token`, `get_by_token` returns only the later row. `_rows` keeps every row, so `all_rows()` and `count()` include the duplicates (L255, L297). `token_map()` is built from `_rows` (L293): each token maps to the symbol of its last row, and two rows of one symbol with different tokens put both tokens in the map, each pointing to that symbol, while `get_by_symbol` returns only the later row's token. Neither `__init__` nor `load` reports, counts or refuses duplicates.

P05-S018. INTERPRETATION (duck typing; P05-S007 item 20): `__init__` accepts any iterable whose elements have `symbol` and `instrument_token` attributes; for other elements the comprehension at L93 raises `AttributeError`; a string passed as `rows` is iterated character by character and so raises `AttributeError` at L93. The only non-test direct construction is `scripts/sr_level_export.py` L141, which passes a path string (section 8, P05-S086; A01 C38b).
